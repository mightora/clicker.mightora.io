What kind of computer are you using?

Download Clicker for Windows (.exe)

Direct download, no GitHub account or build pipeline. This version is unsigned; Windows may warn or block it.

Then:
  1. Open the downloaded mightora-clicker-windows.exe on your computer.

How do I check what I downloaded?
  1. Open the latest release above to view all portable downloads and the SHA256SUMS.txt file.
  2. Check the file's hash against its entry in that list. On Windows, use Get-FileHash .\mightora-clicker-windows.exe -Algorithm SHA256 in PowerShell.
  3. Only run a download you trust. Current builds are unsigned, so your system may refuse to run them.

What if the helper won't connect?

Make sure you copied the entire private code, with a dot between its two long parts. Do not enter a six-character session reference. If you use Python, run python clicker.py and paste the code when prompted.

Simple to use.
Thoughtful by default.

Pairing links use strong random secrets. Only devices with the pairing link can send commands to your session. Sessions expire automatically after two hours, or you can end one immediately.

  • No registration or personal details
  • No presentation content is uploaded
  • Only the four arrow commands are relayed

Network transparency

This online clicker connects to Cloudflare to relay arrow commands between devices. It also loads Mightora branding from GitHub and jsDelivr, plus public workflow badges from GitHub and shields.io. We do not use advertising identifiers or store your commands after your session. To inspect requests, press F12 → Network, enable Preserve log and reload. Browser resource monitors cannot show all network activity.

Because it connects two devices in real time, a fully offline edition is not possible.
